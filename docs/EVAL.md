## 2. 决策规则（v1）

按优先级：

1. **SRM**：`p<0.001` 且 `相对偏差>2%` → `inconclusive`
2. **硬护栏（仅退款率）**：`差值>0.4pp` 且 `p<0.01` → `no-ship`
3. **主指标显著负向**：`p<0.05` 且 `diff<0` → `no-ship`
4. **异质**：交互 `p<0.01`，且一个分层 `BH q≤0.1` 显著为正，另一个分层 `p>0.1` 且效应 `<0.5×` 显著分层 → `iterate`
5. **不显著**：`p≥0.05` → `inconclusive`
6. 其余 → `ship`

**为什么只让退款率做硬护栏**：投诉率基线只有 0.12%，随机波动会产生大量假阳性；P95 延迟在 v1 只展示不判定。退款率基线 1.2%，0.4pp ≈ 相对 +33%，是"实质恶化"的合理阈值。

## 3. 校准结果（120 例，真实决策 vs 引擎决策）

```
true\pred     ship   no-ship  iterate  inconclusive
ship            25       0        0         0
no-ship          0      30        0         0
iterate          0       0       15         0
inconclusive     3       1        0        46
```

| 指标 | 数值 |
|---|---|
| **决策准确率** | **93.3%**（112/120） |
| null 误判为 ship（FPR） | 5.0%（2/40） |
| 正效应漏判（FNR） | 0.0%（0/25） |
| 负效应漏判（FNR） | 0.0%（0/30） |
| 异质识别 | 80%（12/15） |
| SRM 识别 | 100%（10/10） |
| 护栏拦截 | 100%（15/15） |

> **为什么准确率从 96.7% 降到 93.3%**（2026-11-01，M10）：
> 之前的 96.7% 有一部分是靠**过于乐观的标准误**换来的。M10 做了两件事——
> ① 给数据加上真实的按臂基线漂移（两臂是不同用户，天然不同）；
> ② 主指标标准误改用格子级稳健估计，不再假设 i.i.d.。
> 结果是：同一批数据上朴素口径准确率 91.7%、**null 误报率 17.5%**（名义 5%）；
> 换稳健标准误后准确率 94.2%、误报率 10%；再加 CUPED 准确率 93.3%、
> 但**大样本 A/A（1000 次）误报率精确落在 5.00%**。
> 换句话说：准确率降了 3.4 个点，换来的是误报率从失控回到标定值——这是诚实的代价，不是退步。

### 剩下 4 个不一致是什么

全部是 **null 实验的假阳性**（3 个判 ship、1 个判 no-ship，p 在 0.0012–0.031 之间）。
这不是 bug，是 α=0.05 下本就会发生的第一类错误；40 个 null 里出现 4 个并不违背 5% 名义水平（样本量小，区间很宽）。
保留它们是有意的：**不假装 100% 准**，并在评测看板上如实展示失败案例。

## 4b. A/A 自校准（`npm run aa`，1000 次零效应实验）

比"准确率 96.7%"更硬的一类证据：真值就是 0，引擎报了多少次显著一目了然。
生成器用同一套 `buildExperiment`，只是两臂同分布（`archetype = null`）。

| 指标 | 实测 | 名义值 |
|---|---|---|
| 总误报率（非 inconclusive） | **5.00%** | α = 5.00% |
| 正向误报 ship | 2.40% | α/2 = 2.50% |
| 负向误报 no-ship | 2.10% | α/2 = 2.50% |
| iterate | 0.50% | — |
| SRM 误报 | **0.00%** | 0.10% |
| 硬护栏误报 | 0.10% | 0.50%（单侧） |
| 贝叶斯 P(B>A) 均值 | 0.4954 | 0.5 |
| P(B>A) > 0.95 比例 | 5.10% | ≈5% |

每臂平均 19,601 样本、7 天、seed `20261101`。报告写入 `data/aa_report.json`。

**同一个引擎在三种标准误口径下的 A/A 误报率（600 次，`npm run cuped`）**：

| 口径 | A/A 误报率 | 说明 |
|---|---|---|
| i.i.d. 二项标准误 | **11.33%** | 名义 5%，实测失控 2.3 倍 |
| 格子级稳健标准误 | 5.67% | 只换标准误就修好了 |
| 稳健 + CUPED | **5.33%** | 在此基础上进一步收窄且不破坏校准 |

这条对比是本项目的核心证据之一：**在存在格子级基线漂移的数据上，
经典 p(1−p)/n 的 A/A 误报率是名义值的 2.3 倍。**

## 4c. CUPED 方差缩减（`npm run cuped`）

| 指标 | 实测 |
|---|---|
| 前后周期相关系数 ρ（中位） | 0.277 |
| 过离散因子 φ（中位） | 1.42（1 = 纯二项） |
| 方差缩减（中位） | **7.76%** |
| 方差缩减（均值 / p90） | 9.49% / 18.91% |
| 格子数 | 56（7 天 × 2 端 × 2 人群 × 2 变体） |

**归因必须分开讲**（否则就是把标准误的功劳算到 CUPED 头上）：
- 修好误报率靠的是 `seMode = 'robust'`（11.33% → 5.67%）；
- CUPED 的功劳是**在区间已经诚实的前提下再收窄**（方差缩减 7.76%，且不破坏校准）。
- 在本数据集的效应量（±1.5~2.8pp、每臂 2 万）下，三种口径都 100% 检出真实正效应，
  所以 CUPED 的价值体现在**区间宽度**，不在检出数——这点如实写明，不夸大。

## 5. 已知局限

1. **只有二值指标**（转化率）→ 连续指标（ARPU/GMV）与 Welch t 尚未接入决策。
2. **只有 7 天** → 新颖效应、长期效应无法分析。
3. **护栏只有退款率硬拦截** → 投诉率与延迟仅展示（低基数 / 非线性损失）。
   口径已升级：退款率走**非劣检验**（margin = 0.4pp，单侧 α = 0.005，非合并方差），
   延迟改走 **Bootstrap（BCa）** 而不是硬编码 sd 的假 t 检验。
   注意默认口径是「统计显著 ∧ 达到 margin」而非更严的「确认恶化超 margin」——
   因为后者需要观测差值 > margin + z₁₋α·SE ≈ 0.73pp，而本数据集注入的真实伤害只有 0.8pp，
   实测会漏掉约 38%（guardrail 族一致率跌到 46.7%）。这是样本量的约束，不是口径偷懒。
4. **合成数据** → 真实感有限；后续用真实 seed 数据做 sanity check。
5. **主指标已换成稳健标准误，护栏与分层仍是 i.i.d. 口径** → 同样存在过离散下偏乐观的问题；
   A/A 实测硬护栏误报 0.10%（名义 0.5%）尚在容忍内，但严格说应一并换成稳健口径（P2）。
6. **CUPED 需要前周期数据** → 导入的真实数据若没有 `preExposures/preConversions`，
   自动退回普通检验，界面上会明示当前用的是哪个口径。
5. **多重比较只做分层内 BH** → 未做跨维度 FWER 控制（P2）。
