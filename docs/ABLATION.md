## 怎么读这份报告

- **引用覆盖率**低 = 回答无法核对，等于叫你相信它。
- **可疑数字率** > 0 = 模型说了引擎没算过的数，这是最危险的失败模式。
- **口径陷阱识别率** = 问到实验没测的指标时，是否老实说"没有"。
- 规则模式在这三项上通常是满分，但它的语言生硬、只能回答预设意图——这正是 LLM 的位置：**不是替它判断，是替它说话**。
