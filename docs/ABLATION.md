### E001 · 为什么是这个结论？
> **主指标是涨的，但护栏指标没有达标，所以结论是 no-ship。** 依据如下：

1. 主指标支付转化率 +1.95pp，p=4.5e-10，CI [+1.44pp, +2.47pp]，显著正向 [E2][E11]；
2. 但退款率从 1.16% 升到 2.06%，恶化 +0.90pp，p=1.56e-12，超过 0.40pp 的护栏 margin，触发 GUARDRAIL 规则 [E8][E11]；
3. 投诉率 +0.02pp（p=0.64）、P95 延迟 +1ms 均未恶化；退款率是唯一参与决策的硬护栏 [E9][E10][E8]；
4. 分流正常（相对偏差 0.00%），主指标也没有负向，因此排除 SRM 和 NEGATIVE [E11]。

结论：转化率的收益不足以抵消退款率恶化，建议迭代降低退款后再评估。

### E001 · 主指标显著吗？

### E001 · 护栏有没有恶化？

- 退款率：从 1.16% 升到 2.06%，**+0.90pp**，p=1.56e-12，显著恶化，且是参与决策的 gating 指标 [E8]。

- 因此引擎判 no-ship（规则 GUARDRAIL）：主指标支付转化率 +1.95pp（p=4.5e-10）虽是正向，但护栏不通过 [E2][E3][E4][E11]。

## 怎么读这份报告

- **引用覆盖率**低 = 回答无法核对，等于叫你相信它。
- **可疑数字率** > 0 = 模型说了引擎没算过的数，这是最危险的失败模式。
- **口径陷阱识别率** = 主指标是转化率的实验被问到 ARPU 时，是否说清「ARPU 只是副指标、不能当上线依据」（或明确说没有这个口径）。
- 规则模式在这三项上通常是满分，但它的语言生硬、只能回答预设意图——这正是 LLM 的位置：**不是替它判断，是替它说话**。
